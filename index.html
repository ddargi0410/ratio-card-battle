비례식 카드 배틀

비율이 같은 두 비를 찾아 비례식을 완성하세요!

게임 방법
  • 한 번에 카드 8장(4쌍)이 나와요. 비율이 같은 두 장을 차례로 누르면 비례식이 완성돼요. 예: 2 : 3 = 4 : 6
  • 맞히면 +1점, 비율이 다른 두 장을 누르면 −2점이에요. 아무거나 누르면 손해!
  • 4쌍을 모두 찾으면 다음 라운드. 1라운드 1 : 3 같은 쉬운 비부터 100라운드 두 자리 수 비까지 점점 어려워져요.
  • 모은 점수로 상점에서 아이템을 살 수 있어요: 🔍 힌트, 😇 5초 무적, ⚡ 2배 부스터, 🛡️ 방어막, 🧲 점수 자석(친구 점수 10% 뺏기).
  • 헷갈리면 외항의 곱 = 내항의 곱인지 확인해 보세요. 2 : 3 = 4 : 6 → 2×6 = 3×4 = 12

🔌 반 전체 접속을 위한 한 번만 설정

학생 여러 명이 같은 반 코드로 들어와 점수를 겨루려면, 점수를 주고받을 무료 데이터베이스(구글 Firebase)가 필요해요. 처음 한 번만 하면 돼요(약 10분).

  1. console.firebase.google.com에 구글 계정으로 들어가서 프로젝트 만들기 (이름은 아무거나, 애널리틱스는 꺼도 돼요)
  2. Realtime Database를 만들고 잠금 모드로 시작하세요. Authentication → 로그인 방법에서 익명 로그인을 사용 설정하세요. 학생에게 회원가입 화면은 나오지 않습니다.
  3. 이 버전과 함께 제공된 database.rules.json의 전체 내용을 Realtime Database의 규칙에 게시하세요. 기존 공개 규칙은 사용하지 마세요.
  4. 방은 24시간 뒤 접근이 만료됩니다. 반 코드는 수업 참여자에게만 공유하고, 게임 진행 중 선생님 화면을 켜 두세요. 이름 대신 별명을 사용해도 됩니다.
  5. 프로젝트 개요 옆 ⚙️ → 프로젝트 설정 → 아래쪽 내 앱에서 웹 앱(</>) 추가 → 나오는 firebaseConfig 코드를 통째로 복사
